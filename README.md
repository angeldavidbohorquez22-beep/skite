
# 🌽 SKITE | Sistema de Gestión Administrativa y Operativa

SKITE es una aplicación web desarrollada para facilitar la administración de un emprendimiento gastronómico especializado en la venta de esquites (mazorca desgranada con diferentes ingredientes y acompañamientos).

El sistema busca optimizar la gestión de pedidos, el control de inventario y el seguimiento de las operaciones del negocio mediante una interfaz intuitiva y adaptable a diferentes dispositivos.

## 🎯 Objetivo del proyecto

Desarrollar una solución tecnológica que permita centralizar los procesos administrativos y operativos de SKITE, reduciendo el manejo manual de información y facilitando la organización del negocio.

## ⚙️ Funcionalidades principales

- **Panel administrativo:** visualización general de la información y actividad del negocio.
- **Gestión de pedidos:** registro, consulta y seguimiento de pedidos.
- **Control de inventario:** administración de insumos, cantidades disponibles y precios.
- **Productos y recetas:** gestión de productos y sus ingredientes.
- **Control de gastos:** registro de gastos relacionados con los insumos.
- **Vista del cliente:** interfaz para consultar productos y realizar pedidos.
- **Inicio de sesión:** acceso a la interfaz administrativa.
- **Diseño adaptable:** compatibilidad con computadores y dispositivos móviles.

## 🚀 Ejecución del proyecto

1. Descarga o clona el repositorio.
2. Abre la carpeta del proyecto.
3. Ejecuta el archivo `index.html.html` desde un navegador web.
4. Explora las funcionalidades del sistema.

La aplicación funciona como un prototipo web y no requiere instalar un servidor de base de datos.

## 💾 Almacenamiento

El sistema utiliza **LocalStorage** para conservar información dentro del navegador.

Esto permite realizar pruebas de las funcionalidades sin necesidad de configurar una base de datos externa.

> **Nota:** Los datos se almacenan localmente en el navegador utilizado. Esta versión está orientada a la demostración y validación de las funcionalidades del sistema.
